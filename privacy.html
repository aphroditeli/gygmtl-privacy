隐私政策

光因曼陀罗经变卡

本《隐私政策》说明「光因曼陀罗经变卡」（以下简称"本应用"或"我们"）在您使用过程中如何收集、使用、存储、共享与保护您的个人信息，以及您所享有的相关权利。请您仔细阅读，尤其是加粗部分。当您注册、登录或以任何方式使用本应用，即视为您已阅读、理解并同意本政策。

一、我们收集的信息

1. 您主动提供的信息

  • 账号识别码（手机号码 或 电子邮箱地址）——作为登录账号的唯一识别与找回凭证。
  • 密码——经 SHA-256 哈希处理后存储，不以明文保存，我方任何人员均无法反推您的原始密码。
  • 验证码——由华为 AGConnect Auth 发送至您的手机或邮箱，用于注册及异地登录身份核验。验证码仅用于一次性比对，不长期留存。

2. 自动收集的信息

  • 设备识别码（ODID）——用于"一个账号绑定一台设备"的设备绑定机制，防止账号被盗用、转赠或异常多端登录。

3. 我们明确不收集的信息

  • 您的真实姓名、性别、年龄、身份证号
  • 您的地理位置信息（GPS / 基站 / Wi-Fi）
  • 您的通讯录、通话记录、短信内容
  • 您的相机拍摄内容、麦克风录音
  • 您的相册、本地文件（下载的牌卡图片仅写入您设备指定目录，我们不读取）
  • 您的浏览记录、使用行为画像
  • 任何第三方广告追踪识别码（OAID 等，本应用不接入任何广告 SDK）

二、第三方 SDK 与服务披露

为实现账号体系与订阅支付等核心功能，本应用接入以下第三方服务。所传输数据的最终权属与处理受对应服务商隐私政策约束：

SDK / 服务 提供方 使用场景 传输的信息
AGConnect Auth
（认证服务）		 华为软件技术有限公司 注册 / 登录验证码发送与校验 手机号或邮箱地址（用于下发与核验一次性验证码）
华为 IAP Kit
（应用内支付）		 华为软件技术有限公司 订阅购买与订阅状态校验 订单信息、设备识别码（用于订阅权益核销）

除上述两项外，本应用不接入任何数据统计、广告、推送、崩溃收集、性能监控类第三方 SDK。

三、信息的存储方式

1. 本地存储（主要方式）

您的用户数据全部存储在您的设备本地，使用 HarmonyOS 系统提供的安全偏好存储机制（Preferences）。我方不自建服务器存储您的账号、密码哈希、订阅状态、解锁记录、抽牌与下载次数等数据。

  • 卸载本应用后，本地数据随之清除。
  • "注销账户"操作会立即永久删除您在本设备上的所有本地数据。

2. 云端传输（仅限必要场景，不留存）

  • 注册 / 登录验证码：手机号或邮箱 → 华为 AGConnect Auth（仅用于一次性验证，我方不留存）。
  • 订阅购买：订单信息 + 设备识别码 → 华为 IAP（由华为完成扣款与权益发放，我方不留存交易明细）。

四、信息的使用目的

  • 账号管理：建立账号、验证身份、维持登录状态。
  • 设备绑定：将账号与设备绑定，保障账号安全。
  • 订阅服务：处理订阅购买、校验订阅状态、按档位提供对应内容服务。
  • 兑换服务：处理实体牌兑换码或牌阵解锁码的核验与权益发放。
  • 账户注销：彻底删除用户所有本地数据。

本应用不会将您的个人信息用于以上明确目的之外的任何用途，不会用于商业营销、用户画像或对外精准投放。

五、信息的共享、转让与披露

除以下情形外，我们不会向任何第三方共享、转让或披露您的个人信息：

  • 经您本人同意；
  • 为完成订阅购买、验证码下发等核心功能而必须与上文披露的服务方进行的必要信息交换；
  • 法律法规要求，或应有权主管机关的合法调取。

本应用不向任何第三方出售个人信息。

六、您对个人信息的权利

  • 查询与访问：可在「我的」页面查看账号信息和订阅状态。
  • 更正与修改：可修改登录密码。
  • 账户注销：可随时通过「我的 → 注销账户」申请注销，注销后所有本地数据将被永久删除且不可恢复。
  • 权限管理：可在系统设置中随时撤销本应用的网络等授权。

七、信息安全

  • 密码哈希：SHA-256 算法哈希存储，不以明文保存。
  • 设备绑定：一个账号仅限一台设备登录使用。
  • 本地存储：数据存储在设备本地安全区，不经过我方服务器。
  • 防截屏保护：牌卡内容页面启用防截屏（PRIVACY_WINDOW），防止内容被截取。
  • 下载水印：允许下载的牌卡均标注用户专属水印，便于溯源。

八、未成年人保护

本应用不面向未满 14 周岁的未成年人提供服务。如您是未满 14 周岁的未成年人，请在监护人陪同下阅读本政策，并在取得监护人同意后使用。若监护人发现我们在未取得有效监护人同意的情况下收集了未成年人个人信息，可通过下方联系方式要求我们删除。

九、权限说明

本应用仅申请以下系统权限，均与上述业务目的相对应：

  • INTERNET（网络）——用于验证码下发、订阅购买等必要的网络通信。
  • PRIVACY_WINDOW（隐私窗口 / 防截屏）——用于牌卡内容展示页面防止截屏，保护内容版权。

本应用不申请位置、相机、麦克风、通讯录、相册、文件存储、通话记录等敏感权限。
